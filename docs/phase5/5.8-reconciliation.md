# 5.8 — Reconciliation, DoD, PROGRESS

*The 4.5.5 precedent: a phase does not end when its last feature compiles, it ends when the corpus and the
code agree about what was built.*

## Read first

The Phase-5 DoD row in `BUILD_AND_PROMPTS` §2; the PROGRESS Phase-5 gate box; CHANGELOG v1.9.51 (the
Phase-4.5 reconciliation, as the worked example of what this checkpoint looks like done properly).

   smoke result** — the INTEGRATIONS §5 `⚠VERIFY` was closed at 5.0 against the *published reference* only,

5. **Write the PROGRESS entry** and the CHANGELOG section.

## What to check specifically, because it is where drift lands

- **The DoD row's fixture list** vs the fixtures that actually exist and run. It drifted twice before
  (finding 315), through the two passes that *added* fixtures without updating the row.
- **The doc diet** (README §3) vs what a builder actually had to read.
- **The three open items 5.0 deliberately left**: whether the four `Llm.Tasks` model strings move to
  versioned config rows; and D110's two undecided questions (per-arena vs lab-wide scoring; how the base
  rate is computed if proposals span arenas). Either resolve them with a decision row or restate them as
  still open with their trigger — do not let them go quiet.
- **Every `ScratchStore` classification added in this phase**, against `FX-ReproduceDay-AiSession` as the
  arbiter. Five tables were classified across 5.1/5.4/5.5, each with a stated reason; check the reasons
  still hold against the code as built.
- **Whether rule 32's structural guard actually closes.** It was prose-only before this phase; 5.5 built a
  closure. Confirm it fails on a deliberately-added violation, the way D109's four register checks were
  each *proven to fire* rather than merely to pass.

## Gate

The phase DoD: a full month of daily reads under budget with the figure recorded; a cache-hit day costing
~0; a replay provably with no analysis rows; **the live smoke test run, with its result recorded**; and the
nine TEST_PLAN §6 fixtures green (plus the two D113 fixtures added at 5.0/5.7).

Phase 6 does not start while any of this is red — and Phase 6 carries its own inherited prerequisites
(findings 280 and 285, bundled into one fresh calibration generation), which are **not** this phase's work
but do fall due before real strategies register.
