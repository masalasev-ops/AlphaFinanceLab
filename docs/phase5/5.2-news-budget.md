# 5.2 — The D46 news budget (FR-22)

## Read first

`BUILD_AND_PROMPTS` FR-22; MASTER §7 (the news budget is *the* token lever); DESIGN_IMPROVEMENTS §4.2;
INTEGRATIONS §1 (the EODHD `/news` endpoint, cost weight **5**); CONFIG_REFERENCE `Llm.NewsBudget`;
SCHEMA `news_items`; TEST_PLAN §6.

## Build

`EodhdNewsProvider` in `AlphaLab.Data` (the raw fetch, implementing the Core `INewsProvider`), wrapped by
a **`BudgetedNewsProvider` decorator in `AlphaLab.Llm`** implementing the same interface. The decorator
enforces, in this order and **before any token is spent** (rule 13):

1. **Relevance filter** — universe symbols + macro tags.
2. **Title-hash dedupe.**
3. **25-article cap** (`Llm.NewsBudget.MaxArticlesPerRead`).
4. **2,000-char truncation** per article, after local extraction.

Only what survives is persisted to `news_items`, so the table records what the budget **admitted**, not
what the feed returned. Record `truncated_chars` so the budget's effect on what the model saw is
measurable rather than assumed.

## Why a decorator and not a method on the fetcher

The budget must be impossible to bypass. If the enforcement lives inside `EodhdNewsProvider`, a future
caller that reaches for the raw fetch gets an unbudgeted read and nothing fails — the cost shows up on the
bill, not in a test. As a decorator over the Core interface, the only thing composition can hand out is the
budgeted one; the raw fetch is an implementation detail nothing else references. This is the same shape as
`BudgetedAnalysisProvider` from 5.1, for the same reason.

## Rails

- **Pre-token, not post-hoc.** The budget narrows the article set *before* anything is serialized into a
  prompt. A test that only checks the prompt length would pass on an implementation that fetched and
  truncated afterwards, having already paid for the fetch.
- **Degradation order, never a blackout** (D24): `held_positions → cached → neutral_fallback`. An
  over-budget day still answers for the positions that matter. Read it through
  `LlmOptions.ResolvedDegradationOrder` — never the raw property (finding 301).
- **`/news` costs 5 units** against the EODHD daily cap; confirm the weight flows into `api_usage_log`
  through the existing `EodhdEndpointCost` seam. It is already declared there — verify, don't re-add.
- **Dedupe is per-day.** A recurring headline is new evidence on a new day; `ux_news_items_as_of_title`
  already encodes this.

## Gate

- `FR22_NewsBudget_CapsAndDedupes` — 80 raw articles in ⇒ ≤25 admitted, duplicates collapsed by title
  hash, each ≤2,000 chars, **all pre-token**.
- `FR22_Budget_DegradesInOrder` — an over-budget day serves held names, then cached, then the neutral
  fallback; never a blackout; `llm_budget_log.degraded = 1`.
- Assert the raw provider is **not** reachable from composition — the bypass is the failure mode.
