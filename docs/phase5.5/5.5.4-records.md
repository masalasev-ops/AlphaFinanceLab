## The findings this phase produced

Record them; they are the reusable part.

- **The hollow fixture.** An all-seven test built on geometric ramps passed while four of the seven
  signals were numerically degenerate — market return variance ~1e-32, so `bab`/`resmom` divided by
  float noise and `lowvol`/`brk` had every name tied. *Finite, non-negative, non-empty* are not
  assertions about measurement. The lesson generalises past this phase: **a fixture whose synthetic data
  cannot exercise the code path passes for the wrong reason**, and only a strictly-positive,
  must-separate assertion catches it.
- **The floor comparison that meant nothing.** The report's first headline compared the two
  constructions' detectability floors. Long-short is ~2× leverage on the same bet, so it scales TE and
  effect together and detectability — `IR·√T` — is untouched. `resmom:L252` showed it exactly: TE ×3.01,
  effect ×3.01, IR 0.374 → 0.373. **The study refuted its own framing before it refuted anything about
  the world**, which is the argument for running the smoke window before writing the conclusion.
